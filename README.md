# ComfyUI-SolarRenderer
[SolarRenderer](https://github.com/Enderfga/SolarRenderer) Few-Step Generative Reference Rendering

# 1.Installation
```
git clone https://github.com/smthemex/ComfyUI-SolarRenderer
```

# 2.Checkpoints
2 loras [control and 4 steps huggingface](https://huggingface.co/smthem/SolarRenderer) or quark [control and 4 steps quark](https://pan.quark.cn/s/195cca7ba0fd)
